# Blender 3D Models

A collection of original 3D models created using Blender, exploring digital modeling, geometry, materials, and visual design.

## Models

### Classic Mushroom

An original mushroom model designed and created in Blender.

**File:** `mushroom_classic-compressed.glb`

**Software:** Blender

**Format:** GLB (glTF Binary)

The model is exported in GLB format, allowing geometry and associated materials to be viewed in compatible 3D applications.

## Tools & Skills

- Blender
- 3D Modeling
- Mesh Geometry
- Digital Asset Creation
- GLB Export

## Viewing the Models

To view or edit the model:

1. Download the `.glb` file from this repository.
2. Open Blender.
3. Select **File → Import → glTF 2.0 (.glb/.gltf)**.
4. Select the downloaded model.
